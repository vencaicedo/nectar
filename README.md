# 🌿 Nectar Parfums — Tienda de Perfumería con Cotizador WhatsApp & PDF

Sitio web estático moderno para **Nectar Parfums**, especializado en perfumería árabe y fragancias de nicho.

## 🌟 Características
- **Catálogo Centralizado:** Controlado desde `data/catalog.json` para agregar/editar referencias sin tocar código.
- **Diseño Velvet Honey:** Paleta cálida ámbar-crema con tipografía **Fraunces** y **DM Sans**.
- **Precios & Presentaciones en COP:** Soporte para múltiples tamaños (Decants 5ml, 10ml, Frascos 50ml, 100ml) con precios independientes.
- **Scarcity Marketing:** Badges de urgencia según stock ("¡Solo quedan 2 unidades!").
- **Generador de Cotización en PDF:** Genera documentos formales descargables con `jsPDF`.
- **Checkout directo a WhatsApp:** Integrado con el número `+57 301 4972011`.
- **Buscador & Filtros en tiempo real:** Por género, familia olfativa y notas aromáticas.
- **Hosting 100% Gratuito:** Listo para desplegar en GitHub Pages.

Para instrucciones detalladas sobre cómo actualizar productos y alojar la web, consulta [guia_administracion.md](guia_administracion.md).
